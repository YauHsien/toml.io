TOML

[Tom's Obvious Minimal Language]

為您而設的
設定檔之內容格式。

TOML，提供顯見的語法，使您的設定檔寫得最少，卻最好讀。 TOML 能準確無誤地對照為一份雜湊表。 TOML 能輕易地轉寫為各種程式語言所用的資料格式。

enabled = true

TOML 重視人性

TOML 設定為最小化的檔案規格：

  • 因清楚的語法而好讀
  • 對照為雜湊表，準確無誤
  • 為了搭配各種程式語言，容易轉寫為適當的資料格式
TOML 提供有用的資料型別
  • 鍵值配對
  • 陣列
  • 表
  • 內嵌表
  • 含表陣列
  • 整數與浮點數
  • 布爾變數
  • 日期與時間，其中可指定偏移量
TOML 已廣受支援

TOML 已有今日許多主流程式語言的實作：包括 C、 C#、 C++、 Clojure、 Dart、 Elixir、 Erlang、 Go、 Haskell、 Java、 JavaScript、 Lua、 Objective-C、 Perl、 PHP、 Python、 Ruby、 Rust、 Scala、 Swift 等等 and plenty more.

豐富的字串語法

我們有四種書寫字串的辦法：包括基本式、多行基本式、字面式與多行字面式等。 基本式字串用雙引號夾住： 

str1 = "我是字串！"
str2 = "我可以再 \"夾一層引號\" 。"
str3 = "Name\tJos\u00E9\nLoc\tSF."

多行基本式字串的兩端分別用連續三個雙引號夾住，於是這種字串可以折行。 而如果你想給多行字串美美的縮排，你可以在每一行的結尾分別放置一個反斜線， TOML 會自動幫你去除下一行開頭的空白文字： 

str1 = """
Roses are red
Violets are blue"""

str2 = """\
  The quick brown \
  fox jumps over \
  the lazy dog.\
  """

str2 字串的內容會是 "The quick brown fox jumps over the lazy dog." (那是純粹的一行文字，其中沒有折行符號).

字面式字串要用單引號夾住。 在這種字串裡頭不處理逸出序列，所以是字面式，你得到的字串就是你看到的字串： 

path = 'C:\Users\nodejs\templates'
path2 = '\\User\admin$\system32'
quoted = 'Tom "Dubs" Preston-Werner'
regex = '<\i\c*\s*>'

因為沒有逸出序列，在基本式字串裡不能寫一個單引號被兩個單引號夾住。 因此我們有多行字面式字串： 

re = '''I [dw]on't need \d{2} apples'''
lines = '''
The first newline is
trimmed in raw strings.
All other whitespace
is preserved.
'''

數值

TOML 支援整數、浮點數、無窮數以及 NaN。我們也能使用科學記號表示法與千分位表示法。 

# 整數
int1 = +99
int2 = 42
int3 = 0
int4 = -17

# 開頭是 `0x` 的十六進制整數
hex1 = 0xDEADBEEF
hex2 = 0xdeadbeef
hex3 = 0xdead_beef

# 開頭是 `0o` 的八進制整數
oct1 = 0o01234567
oct2 = 0o755

# 開頭是 `0b` 的二進制整數
bin1 = 0b11010110

# 分數
float1 = +1.0
float2 = 3.1415
float3 = -0.01

# 指數
float4 = 5e+22
float5 = 1e06
float6 = -2E-2

# 分數與指數
float7 = 6.626e-34

# 千分位表示法
float8 = 224_617.445_991_228

# 無限數
infinite1 = inf # positive infinity
infinite2 = +inf # positive infinity
infinite3 = -inf # negative infinity

# NaN
not1 = nan
not2 = +nan
not3 = -nan

日期與時間

TOML 能支援日期、時間以及帶有偏移量的日期與時間。 

# 帶有偏移量的日期與時間
odt1 = 1979-05-27T07:32:00Z
odt2 = 1979-05-27T00:32:00-07:00
odt3 = 1979-05-27T00:32:00.999999-07:00

# 本地日期與時間
ldt1 = 1979-05-27T07:32:00
ldt2 = 1979-05-27T00:32:00.999999

# 本地日期
ld1 = 1979-05-27

# 本地時間
lt1 = 07:32:00
lt2 = 00:32:00.999999
